## 二、典型片段：一次真实的权衡

ADR-007（技术栈切换）是本阶段代价最大的一次决策：
Java + Vue 的方案在架构文档和 14 个 Issue 里已经写死了技术备注，切换意味着这些全部重写。
判断依据是三个人的语言基础 + CI 维护成本：两套运行时 = 两套缓存、两套安全更新、两倍 CI 时间。
最终选 Python（FastAPI + Jinja2 + HTMX），CI 从 4 分钟降到 1 分 40 秒，本地环境从「JDK + Maven + Node + MySQL」降到「Python + SQLite」。
代价是返工约 6 小时（文档重写 4h + Issue 备注 2h）。这件事记在 ADR 里，包括被否决的三个方案。
