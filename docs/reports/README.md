## 为什么报告也要入库

课程要求过程材料在 GitHub 上可追溯。报告只交到教学平台的话，仓库里就只剩「代码」，
看不出「哪一周做了什么、当时怎么判断的」。入库带来三个好处：

1. 报告里承诺的「下阶段计划」可以直接对照 Issues 和 Milestones 验收
2. 报告与 SRS 的版本、功能数量、Issue 编号能相互印证，避免各说各话
3. 答辩前整理材料时，不必再回头翻聊天记录找某个文件

## 命名约定

```
第<组号>组第<次序>次项目进展报告-<提交日期 YYYYMMDD>.docx
```
