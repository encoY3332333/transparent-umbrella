# 会议纪要（Meeting Minutes）

> 课程考核 B6「协作与文档」要求：**会议记录须入库存档，至少 4 次**。
>
> 本目录是会议纪要的**入库版本**（Markdown，便于在 PR 中查看 diff）。同时提交的 `.docx` 版本放在 `docs/meetings/archives/`，两份内容一致——docx 用于打印与随附件包提交，md 用于版本追溯。

## 归档约定

- 文件名：`YYYY-MM-DD-第N次-<会议类型>.md`，日期为**实际开会日期**
- 每次会议必须有：时间、地点、主持人、记录人、出席名单
- 议题必须有**结论**，没有结论的写成「未决，下次会议继续」，不能留空
- 行动项必须有**责任人 + 截止时间**，没有责任人的行动项等于没有
- 会议纪要由**记录人**在会后 24 小时内提交 PR（分支 `chore/<issue号>-meeting-minutes-YYYYMMDD`），由主持人 Approve 后合入
