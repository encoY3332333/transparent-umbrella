# [Feature] 行程收藏与分享

## 背景 / Background

自由行很少是一个人做决定。问卷 Q10 显示大部分受访者愿意把行程发给同行伙伴看，Q11 中多数人希望导入手机日历。分享不只是「方便」，它能带来自然的传播与留存。

对应 SRS：3.3.6 · 用例 UC-06

## 需求描述 / Description

保存行程到「我的行程」，生成 7 天有效的只读分享链接与二维码，支持导出 .ics 日历文件。

## 任务清单 / Tasks

- [ ] 后端：`POST /api/itineraries/{id}/save` 保存并命名（默认「目的地 + 起止日期」）
- [ ] 后端：`POST /api/itineraries/{id}/share` 生成短链（带签名 token，TTL 7 天）
- [ ] 后端：`GET /api/share/{token}` 只读访问接口，**必须使用脱敏 DTO**（剔除手机号、真实姓名）
- [ ] 后端：`ExportService.toICS()` 生成 .ics，正确处理跨天活动与时区
- [ ] 后端：单账号保存上限 50 份（BR-18），超出时提示删除最早的一份
- [ ] 前端：分享面板（复制链接、二维码、导出日历三个 tab）
- [ ] 前端：`MyItinerariesView.vue` 我的行程列表（缩略图 + 名称 + 日期 + 状态）
- [ ] 测试：`ShareServiceTest` 覆盖链接生成、过期校验、签名篡改拒绝、脱敏字段
- [ ] 测试：`IcsExportTest` 覆盖单日活动、跨天活动、多时段活动

## 验收标准 / Acceptance Criteria

- [ ] AC-1 保存操作 1 秒内完成，并在「我的行程」列表首部出现该行程
- [ ] AC-2 分享链接在未登录的浏览器中可正常打开并完整展示行程，且无可编辑控件
- [ ] AC-3 导出的 .ics 可被 Google 日历与手机系统日历正确导入，事件数量与活动数量一致
- [ ] 分享链接 7 天后访问提示「链接已失效」，并可申请重新生成
- [ ] 分享接口响应体中**不含**手机号、真实姓名等个人信息（BR-17）
- [ ] 分享链接被篡改（token 签名不匹配）时返回 403，不泄露行程内容
- [ ] 同名行程已存在时提示「覆盖 / 另存为副本」
- [ ] 单账号第 51 份行程保存时被拒绝，并提示最早的一份名称

## 安全提示

分享链接的 token 必须服务端签名（HMAC-SHA256，用 `SHARE_SIGN_SALT`），不能只用自增 ID——否则可以遍历他人行程。
