## 基线说明

**V1.0 于 2026-11-09 经组内需求评审会（第 1 组第 2 次会议）确认后冻结为需求基线。**

冻结后任何需求变更都必须走以下流程，口头协商不作为变更依据：

1. 新建 Issue（模板：功能需求），标题前缀 `[Feature]`，在「背景」中写明变更理由
2. 组内评审，至少 1 名非提出者 Approve
3. 修订本目录下的 SRS 文档，更新「文档变更历史记录」表与版本号
4. 在 PR 描述中写 `Closes #<issue号>`
5. 合并后同步更新 `docs/api.md`（涉及接口时）与 `CHANGELOG.md`
